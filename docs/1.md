## 1. 项目现状与目标

### 1.1 背景
- 主项目：D:/008/DriFox-0.4.14（Python 3.14 + PyQt5 桌面对话助手）
- 借鉴源：
  - D:/008/prime-agent-0.7.1（TS 编码/研究 Agent）：Harness 记忆 + /refine + RLM 内核 + 后台保活
  - D:/008/reverse-skill-1.0.1（安全技能路由）：确定性路由层（routing.json 单一事实源/回归测试/工具索引）

### 1.3 上下文三层模型（核心认知）
| 层 | 载体 | 存活范围 | 内容 |
|---|---|---|---|
| 持久层 | Harness（SQLite 4 类条目） | 跨会话/跨天 | 经验、偏好、技能定义、专家规范 |
| 工作层 | RLM 内核（ipykernel Python 状态） | 跨轮次/跨对话续 | 变量、文件内容、解析结果 |
| 对话层 | LLM 上下文窗口 + 结构化压缩 | 单轮 | 当前任务最小上下文 |

模型只看对话层；需要时从工作层按需取；对话层满 → 压缩 → 沉淀进持久层。

## 2. 总体执行计划（Gate 门禁制）
```
Gate 0 ── L1 ── Gate1 ── L2 ── Gate2 ── L3 ── Gate3 ── L4 ── Gate4 ── L5 ── 验收
基线锁定   记忆精炼   门禁检查   路由层   门禁检查  RLM内核  门禁检查   保活   门禁检查   特工团队  最终回归
```
- 一层一源：每层只借鉴一个来源；只改本层文件；无关变更不做。
- 完成才 commit：未验证不提交；失败只修本层；连续 3 次失败停止盲改（重读代码找根因）。
- 不重跑已通过层。
- 回归锚点：每层出口 pytest tests/ 全量回归。
- 证据铁律：验证通过必须有命令输出/测试报告原文。

## 3. 各层执行细节

### Gate 0：基线锁定（执行会话首发动作）
1. cd D:/008/DriFox-0.4.14 && uv sync --group dev
2. ruff check . && ruff format --check .（记录基线告警数）
3. pytest tests/（记录通过/失败数；历史失败单独列出标记「遗留」）
4. 产出 tests/BASELINE.md（基线测试数/失败清单/核心模块行数）
5. git commit -m "chore: baseline lock"（hash 写入 BASELINE.md）

### L1：Harness 记忆 + /refine（源：prime harness.py + refinement 工作流）
范围：
1. app/core/store/：扩展 4 类条目（kind: prompt/memory/skill/subagent）+ 字段 title/content/source/scope(local|global)/version/created_at/updated_at；refine_history 快照表（before/after JSON）
2. 新增 app/core/harness/ 包：entries.py（CRUD）、refine.py（轨迹→LLM 补丁→校验→落库→快照）、formatter.py（注入格式）
3. 命令：plugins/system/commands/refine.md（/refine [instructions] [--global]，默认 local）
4. 注入：format_memory_context hook 并入 harness 条目
5. 回滚：/refine --rollback <id>
测试（>=30 条）：test_harness_entries.py / test_refine_chain.py / test_refine_injection.py + 全量回归
出口：/refine 冒烟出变更 + 快照可回滚 + pytest 全绿 → commit

### L2：路由层（源：reverse-skill routing.json / MASTER-ROUTING）
范围：
1. app/core/router/：routing.json（单一事实源）+ router.py 评分器（must/mustAll/exclude 正则 + priority 决胜 + fallback）+ 工具可用性检测
2. 命令：/route <任务描述>（PRIMARY 路径 + 依据）；/router（规则管理）
3. Hook：PreUserMessage 可选自动路由（默认关）
4. 内置规则初集 20-30 条
5. 回归 tests/test_router.py：100+ 用例（CI 常驻门）
出口：路由测试全绿 + /route 真实示例命中正确 → commit

### L3：RLM 执行内核（源：prime kernel/index.ts）
范围：
1. pyproject 加入 ipykernel、jupyter-client、dill
2. app/core/engine/kernel_manager.py：启动 ipykernel；jupyter_client 连接；execute(code) cap/abort；dill 快照恢复
3. host bridge：kernel 内 host_request shim
4. 工具：make_python + 登记进 BuiltinTools
5. 跨轮状态验证
测试：tests/test_kernel_manager.py（start/execute/状态跨轮/abort/快照恢复）
出口：内核单测绿 + 手动冒烟（x=42 下一轮 x+1=43）→ commit

### L4：后台保活（轻量 uvicorn 驻留）
- api_server.py 扩展为常驻执行进程：提交任务 / SSE 事件流 / 会话列表 / 快照下载；--serve 模式独立跑（无 UI）
- UI attach：窗口连接 SSE、回放（快照+事件）；关闭窗口仅 detach 不杀服务；任务继续
- 恢复：应用重启 → 快照重载 → 未完成任务继续
注意：L3 内核挂服务进程内（非 UI 进程）；仅做服务接口层改动，不推翻 backend 设计
验收：集成测试（UI 关 → 服务保持 → 重开 UI attach）+ 重启恢复

### L5：特工团队（源：GrandCode 四角色 + subagent_dag）
- 内置 agents（plugins/system/agents/）：hypothesis（假设）/ solver（实现）/ test-generator（对抗用例）/ summarizer（压缩提炼）
- /mission 命令 → subagent_dag 编排：hypothesis → solver → test-generator（跑挂回环 solver，预算复用 AutoLoop config）
- 对抗循环：用例执行失败带错误回环（最多 N 轮）
验收：端到端任务跑通回环；10 样题过 8 → commit
